Thiết Kế Bento Grid Hiện Đại Với grid-row: span 2

Phong cách bố cục Bento Grid (lấy cảm hứng từ khay cơm Bento Nhật Bản) đang là xu hướng hàng đầu trong thiết kế UI/UX hiện nay. Nhờ vào grid-row: span 2;, một khối thẻ chính có thể kéo dài gấp đôi chiều cao so với các ô phụ một cách linh hoạt.

Vị trí thẻ cao (Tall Card):
Featured Feature
🚀 AI Intelligence Engine
Tích hợp phân tích dữ liệu tự động theo thời gian thực với mô hình học sâu thế hệ mới.
grid-row: span 2;
Productivity
⚡ Tốc độ xử lý siêu nhanh
Tăng hiệu suất làm việc nhóm lên gấp 3 lần với bộ công cụ trực quan.
grid-column: span 2;

/* Bento Grid: 3 cột, mỗi hàng cao 140px */ .bento-grid { display: grid; grid-template-columns: repeat(3, 1fr); grid-auto-rows: 140px; gap: 16px; } /* Thẻ Featured kéo dài qua 2 hàng */ .card-tall { grid-row: span 2; /* Tự động kéo dài 2 hàng */ grid-column: 1; }
